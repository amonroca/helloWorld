# Overview

This is a Hello World program written in Python that displays an ASCII art banner, a time-based greeting (Good morning / afternoon / evening), and the current date and time in American format.

The purpose of this project is to go beyond a simple `print("Hello, World!")` and demonstrate basic Python concepts in a fun and practical way — including conditional logic with ternary operators and string formatting with `strftime`.

# Development Environment

This software was developed using Visual Studio Code with the Python extension. The code was run and tested using the built-in debugger and the integrated terminal on Windows.

The project is written in Python 3, using only the standard library (`datetime` module — no external packages required).
